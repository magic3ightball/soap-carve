# 비누 깎기 v2 설계 (2026-10-27)

v1(soap-carve)을 사용자가 "너무 비누 같지 않다"고 평가해서 다시 설계한다.
이번 v2는 세 가지에 집중한다. **불투명·무광 비누**, **밝은 깎인 면**, **이어서 말리다 끊기는 리본**.

## 왜 v1이 비누 같지 않았나 (2026-10-27 직접 깎아 보고 비교)
- v1은 모든 비누를 투명 녹여 붓기 비누로 바꿨다 → 화면에서는 젤리·레진·유리처럼 보인다.
  투명해서 깎은 자국이 거의 안 보이고, 깎은 면과 겉면의 대비도 없다.
- 칩: 길이를 2.2~3.8 cm 사이에서 무작위로 미리 정해 두고 그 길이가 되면 끊는다. 0.8초 뒤부터 작아지며 사라진다.
  → 끊기는 이유가 보이지 않고, 작아지며 사라지는 모습이 가짜처럼 보인다.
- 비교 대상인 [C2251340/soap](https://github.com/C2251340/soap)은 깎인 면을 겉면보다 밝게 칠한 점이 비누다웠다.
  대신 조각이 아니라 한 겹씩 벗기기만 하고, 큐브가 쌓여 비누를 가린다.

## 근거 (조사 결과)
- 자유 조각에는 아이보리 같은 **불투명 비누**가 무르고 다루기 쉽다. 글리세린·투명 비누는 더 단단하고 잘 부서진다.
  ([hobbystack 칼 가이드](https://hobbystack.net/tools/best-soap-carving-knife), [Woodcarving Illustrated 포럼](https://forum.woodcarvingillustrated.com/forum/woodcarving-illustrated/woodcarving/carving-wood-materials/2369-soap-carving))
- **촉촉한(새) 비누는 말린 리본이 나오고, 오래 마른 비누는 부스러진다.** 모서리가 떨어지고 얇은 곳이 부러진다.
  너무 새 비누는 깎이지 않고 뭉개진다. 날이 무디거나 너무 깊게 깎아도 부서진다. (같은 출처들)
- 비누 깎기 ASMR 시청자는 말려 나오는 무른 비누를 좋아한다. 바삭한 소리 쪽은 따로 오래 말린 비누를 쓴다.
  ([TODAY](https://www.today.com/today/amp/tdna123334), [GMA](https://www.goodmorningamerica.com/video/55666700))
- 금속 절삭(정성적 경향): 칩이 두꺼울수록 잘 말리고 잘 끊긴다. 말림 반지름이 크면 잘 안 끊긴다.
  ([Mitsubishi 칩 제어](https://www.mmc-carbide.com/permanent/courses/75/factors-affecting-chip-control.html))
  → 아래 '굽힘 변형률로 끊기' 규칙의 근거다. 비누 수치는 없으니 값은 눈으로 맞춘다.
- 무광 왁스 재질의 실시간 근사: wrap 조명 + 그림자 경계의 따뜻한 색 번짐 + 얇은 곳 뒤 빛.
  ([GPU Gems 16장](https://developer.nvidia.com/gpugems/gpugems/part-iii-materials/chapter-16-real-time-approximations-subsurface-scattering),
  [UE4 Subsurface](https://docs.unrealengine.com/4.26/en-US/RenderingAndGraphics/Materials/LightingModels/SubSurface))

| 카메라·되돌리기·소리 구조 | 리본 메시와 셰이더(`fsChip`), 끊김 소리 |

v1 배포판(soap-carve.vercel.app)은 그대로 두고, 같은 저장소의 `v2` 브랜치에서 작업한다.
v1 엔진을 그대로 쓰지만 손맛이 같아질 걱정(공룡 발굴 키트 교훈)은 적다. 이번 불만은 엔진이 아니라 재질과 칩이었기 때문이다.

## 1. 재질: 불투명·무광 + 밝은 깎인 면
비누를 세 층으로 본다.

| 층 | 색 | 광택 | 결 |
|---|---|---|---|
| **겉면(껍질)** | 기본색, 채도 약간 높고 살짝 어둡다(마른 겉) | 거의 없음 (roughness ≈ 0.7) | 미세 잡음 + 가루 같은 얼룩 |
| **깎인 면** | 기본색보다 밝게 (+10% 내외, 하얀 쪽으로) | 은은한 왁스 광택 (roughness ≈ 0.35) | 칼 방향 결 (v1의 0.45 mm 결 유지) |
| **얇은 곳** (모서리·리본) | 뒤에서 빛이 비쳐 따뜻하게 밝아짐 | — | — |

- 조명: `wrap = max((N·L + 0.4)/1.4, 0)`. 그림자 경계에는 기본색보다 따뜻하고 채도 높은 색을 섞는다 (GPU Gems식).
- 얇은 곳 판단: 표면에서 안쪽으로 SDF를 2~3번 찍어 두께를 추정한다 → `exp(-두께/τ)`만큼 뒤 빛을 더한다.
  모서리·얇은 날개만 은은하게 비친다. 굴절 없음, 속 들여다보기 없음.
- **깎인 면과 겉면의 경계선**이 또렷해야 "깎았다"가 보인다. tx.g(면 종류)를 좁은 smoothstep으로 섞는다.
- 비누 종류(불투명 4종): 아이보리 흰 / 라벤더 파스텔 / 민트 / 복숭아. 무늬 없음(v2 첫 단계). 마블은 나중에.

## 2. 리본: 이어서 나오고, 말리고, 이유 있게 끊긴다
리본 한 개 = 칼이 쉬지 않고 깎는 동안 날 뿌리에서 계속 자라는 띠.

**자라기**: v1 `feed()`와 같다. 깎인 단면적으로 두께 t를 정하고, 접촉 폭으로 폭 w를 정한다.
마디마다 t가 따로 있어서, 깊이를 바꾸면 리본 두께도 따라 변한다. **미리 정한 최대 길이는 없앤다.**

**말림**: 날 면을 타고 오르다 감긴다(v1 운동학 방식 유지 — 안정적).
말림 반지름은 `R = R0 · (t/t0)^0.5 · f(칼 기울기)`로 정한다. 두꺼울수록 크게, 칼을 세울수록 촘촘하게 감긴다.

**끊김** — 아래 중 하나라도 맞으면 그 마디에서 끊는다. 끊긴 앞부분은 강체가 되어 떨어진다.
뿌리 쪽은 그대로 계속 자란다. 그래서 한 획에서 리본이 여러 개 나올 수 있다.
1. **굽힘 변형률** ε = t / (2R) > ε_break(마름 정도). 두껍고 촘촘하게 말린 리본은 금방 끊기고, 얇은 리본은 길게 감긴다.
2. **약한 곳**: 리본마다 무작위 위치 몇 군데에서 ε_break를 낮춘다(30% 내외). 모든 리본이 같은 길이가 되지 않게 한다.
3. **칼 꺾음**: 진행 방향이 한 번에 35° 넘게 바뀌면 끊는다.
4. **칼이 뜸**: 단면적이 MIN_AREA 아래로 0.25 cm 넘게 이어지면 통째로 떨어뜨린다(v1과 같음).
5. **무게**: 10 cm를 넘으면 자기 무게로 뿌리에서 끊는다(안전 상한).

**마름 정도(한 개의 값, 촉촉 ↔ 바삭)**: 조사에서 나온 "새 비누는 말리고 마른 비누는 부서진다"를 값 하나로 묶는다.
- 촉촉: ε_break 높음 → 긴 리본, 소리 부드러움.
- 바삭: ε_break 낮음 → 짧게 말린 조각 + 잔 부스러기(v1 `crumbs`) 증가, 소리 바삭.
- 처음엔 중간값. HUD 슬라이더 하나로 노출한다.

**떨어진 뒤**: 강체로 떨어진다(v1 physics 유지). **작아지며 사라지기는 없앤다.**
화면 아래로 빠지면 지운다. 비누 위에 걸리면 그대로 남는다. "부스러기 치우기"로 지운다. 개수 상한 160개는 유지한다.

**리본 모양·색**
- 단면은 가운데가 두껍고 가장자리가 얇은 초승달이다. 가장자리는 얕게 깎일수록 너덜너덜하게(폭에 잡음).
- 두 면의 색이 다르다. 리본 바깥(원래 표면 쪽)은 그 자리가 겉면이었으면 겉면 색, 안쪽(칼에 닿은 쪽)은 밝은 깎인 면 색.
  첫 겹을 깎을 때 리본 바깥에 껍질 색이 보이는 게 진짜 비누 같은 단서다.
- 얇을수록 비친다: 투과 = `exp(-t / 0.03 cm)`. 0.2 mm 리본은 빛을 받으면 은은하게 비친다. 1 mm는 불투명하다.
- 말린 안쪽은 어둡게(가림) 칠한다 — 감긴 각도로 간단히.

**소리**
- 붙어 있는 동안 계속 "사각"(v1 그대로, 두께에 따라 음높이).
- 끊길 때 "틱" 한 번(두꺼울수록 낮고 크게, 바삭할수록 날카롭게). 떨어져 닿을 때 "톡"(v1 hit).

## 3. 조작 (첫 단계는 줄인다)
- 도구: 칼(1), U자 끌(2)만. 자르기·물 묻히기·목표 모양은 v2 첫 단계에서 숨긴다(코드는 남김).
- 그 밖에는 v1과 같다: 비누 위 드래그 = 깎기, 빈 곳 드래그 = 돌리기, 스크롤 = 깊이, Q/E = 기울기, ⌘Z.
- 추가: 마름 정도 슬라이더.

## 완료 기준 (숫자로 확인)
| 항목 | 기준 | 확인 방법 |
|---|---|---|
| 불투명 | 비누 뒤 배경이 비치지 않음 | 비누 가운데 픽셀이 배경색과 다름, `transmit` 호출 없음 |
| 밝은 깎인 면 | 같은 조명에서 깎인 면 평균 밝기 ≥ 겉면 × 1.08 | 윗면을 반만 깎고 두 영역 휘도 비교 |
| 경계선 | 깎인 면/겉면 경계 폭 ≤ 3 px (기본 확대) | 경계를 가로지르는 휘도 단면 |
| 이어지는 리본 | 촉촉·깊이 0.8 mm·일정 속도 4 cm 획 → 첫 리본 ≥ 2.5 cm 붙어 있음 | `chips.stats` + 마디 수 |
| 이유 있는 끊김 | 바삭·같은 획 → 리본 ≥ 3개, 각 ≤ 1.5 cm | 같은 측정 |
| 두께 따라 | 깊이 1.6 mm 리본의 평균 길이 < 0.4 mm 리본의 평균 길이 | 깊이별 10획 평균 |
| 얇으면 비침 | 0.2 mm 리본이 역광에서 1 mm 리본보다 밝음 | 고정 장면 회귀 캡처 |
| 성능 | 실제 Chrome 전체 화면에서 깎는 중 프레임 ≤ 16 ms | 사용자 환경에서 측정 (숨은 pane 수치는 믿지 않음) |

자동 측정은 `tools/regress`에 장면 몇 개를 더한다(`?regress=v2-material`, `?regress=v2-ribbon`).

## 작업 순서 (각 단계 끝에 사용자가 만져 보고 피드백)
0. 정리: v1 미커밋 변경(녹음 샘플 구조·스크래치 비누)을 v1 쪽에 커밋 → `v2` 브랜치 생성.
1. **재질**: `transmit` 경로 제거, 불투명 4종, 겉면/깎인 면/얇은 곳 셰이딩. → 화면 확인 + 밝기 기준.
2. **리본 규칙**: 최대 길이 삭제, 변형률·약한 곳·꺾음·무게 끊김, 마름 정도 값, 사라지기 삭제. → 길이 통계.
3. **리본 모양·색**: 초승달 단면, 두 면 색, 얇은 비침, 말린 안쪽 어둡게.
4. **소리**: 끊김 "틱", 마름 정도에 따른 음색.
5. 배포는 사용자가 만져 보고 괜찮다고 한 뒤에 별도 프로젝트 이름으로(예: soap-carve-v2). v1 링크는 유지.

## 아직 모르는 것
- ε_break·R0·τ 실제 값: 비누 수치 자료가 없다. 처음 값은 눈으로 맞추고, 사용자 피드백으로 조정한다.
- 실제 비누 리본 사진·영상과 나란히 비교하지 못했다. 1단계 전에 레퍼런스 이미지를 몇 장 모으면 좋다.
- 리본을 운동학적 모양으로 계속 두면, 자라는 동안 비누 표면을 뚫는 경우가 있을 수 있다(v1에서는 s0 띄우기로 막음).
