## 목표 모양 깎기 (2026-10-06 추가)
- HUD에서 자유 조각 / 물고기 / 토끼 선택 → 새 비누에서 시작. 오른쪽 위에 목표 모양 미리보기(천천히 회전).
- 가이드(G): 비누 표면을 목표까지 남은 거리로 색칠 — 주황+2 mm 등고선 = 더 깎을 곳, 초록 = 목표면 ±0.5~1 mm, 빨강 = 너무 깎음.
- 채점(`src/targets.js` `score`): 허용 오차 0.8 mm 밖만 센다. 진행 = 1 − 남은 군살/처음 군살, 너무 깎음 = 목표 안쪽을 깎은 비율.
  진행 ≥ 90% && 너무 깎음 < 10%면 완성 토스트. 획이 끝날 때·되돌리기 때 다시 계산(전체 복셀 1회 순회).
- 목표 SDF는 JS 함수(타원체 smooth union)로 CPU 배열을 만들고 r16float 3D 텍스처로 한 번 올림. 고를 때 약 0.6초 걸림.
- 검증: 목표 SDF+0.4 mm까지 깎은 상태를 직접 만들어 진행 100%·너무 깎음 0%·완성 토스트 확인(물고기·토끼),
  칼로 5획 깎기 → 진행 0→5%, 몸통 가운데를 일부러 깊게 → 너무 깎음 0.3%, 빨강·초록 표시 확인.

## 덩어리 자르기 도구 (2026-10-06 추가)
- 1/2 키 또는 HUD로 칼 ↔ 덩어리 자르기 전환. 자르기: 화면에 선을 그으면 (눈 위치+선)이 이루는 평면으로 잘라 **부피가 작은 쪽**을 떼어 냄.
  긋는 동안 떼어 낼 쪽을 붉게 미리 보여 줌(양쪽 부피는 2칸 건너 표본, 60 ms마다). 자르기 모드에선 두 손가락 스크롤 = 회전.
- 떼어 낸 덩어리: surface nets 메시(작으면 0.5 mm, 크면 1 mm) + 공용 강체(`src/physics.js`), 멈추고 1초 뒤 0.5초 동안 작아지며 사라짐.
- 남는 쪽은 평면에서 0.3 cm 안쪽까지만 고친다(깊은 안쪽 거리는 과대평가돼도 무방) → 바뀐 영역만 업로드.
- 실측: 자르기 한 번 45~140 ms(작은 덩어리를 고해상도 메시로 만들 때 가장 느림), 이후 프레임 13~15 ms. ⌘Z로 덩어리째 되돌아감.
- 칼 최대 깊이 3.5 → 6 mm (폭 최대 1.8 cm).

## 소리 (2026-10-06 추가, `src/sound.js`)
- Web Audio 합성, ASMR 쪽(가깝고 바삭), 이어폰 기준 스테레오. 첫 클릭/키 입력 때 AudioContext 생성. M = 음소거(localStorage 저장).
- 깎기: 깎인 부피가 `burstVol·(0.6+깊이·5)`만큼 쌓일 때마다 "사각" 1번 = 대역 잡음 알갱이 ~5개 묶음(+고음 클릭).
  깊을수록 낮고 크게, 칼 화면 x 위치로 좌우. 바탕 "쓱"은 깎는 속도·깊이에 비례. 칩 떨어짐 "톡", 부딪힘 톡/쿵(충돌 속도), 자르기 "썩".
- `?debug` → 오른쪽 아래 소리 다듬기 패널(11개 값), '값 복사'로 JSON을 받아 `SOUND_DEFAULTS`에 넣으면 기본값이 된다.
- 검증(OfflineAudioContext로 렌더해 수치 측정, 귀로는 확인 못 함): 클리핑 없음(최대 0.31), 느리게→빠르게 알갱이 82→359·RMS −40→−32 dB,
  깊게 깎으면 영교차율 9.7k→6.8k/s(낮아짐), 오른쪽 칼이면 오른쪽 +9 dB, 활성 구간 깎기 −32 dB·자르기 −29 dB·덩어리 쿵 −28 dB·칩 톡 −41 dB.
- 다음: 사용자가 들어 보고 패널로 다듬은 값 반영, 원하면 실제 비누 깎는 소리 녹음을 알갱이 재료로 교체.

## 둥글게 다듬기 (2026-10-07 추가)
- 사용자 피드백: "표면이 둥그렇게 잘리지 않아 조각이 힘들다".
- 칼 단면을 평평한 바닥+수직 벽 → **둥근 끌(반타원)**으로 바꿈(`sdf.carve`). 획을 겹치면 턱 없이 이어진다.
- **물 묻히기(3)** (처음 이름 '다듬기', 사용자 요청으로 변경 — 젖은 비누가 녹아 둥글어지는 비유): 붓 안 거리장을 상자 흐림(폭 ∝ 붓 크기, 축마다 2번)한 값과 비교해 깎는 쪽으로만 바꿈(`sdf.sand`).
  볼록 모서리·홈 사이 턱만 깎이고 오목한 곳은 안 채움, 평평한 면은 그대로. 스크롤 = 붓 크기(2.4~20 mm), 문지르는 동안 "스윽".
- 실측: 90° 모서리에서 붓 16 mm로 8번 → 모서리 반지름 3.3→4.8 mm(점점 느려짐), 평평한 윗면 변화 0,
  홈 4줄을 3번 문지르면 단면 거칠기(2차 차분 합) 0.36→0.16. 프레임당 0.6~1.6 ms.
- 주의: 흐림 폭이 고정이면 그 크기만큼만 둥글어지고 더 문질러도 그대로였다 → 폭을 붓 크기에 비례시킴.

  실측: 앞면 윗부분을 적시면 2초 동안 젖은 가장 낮은 점이 y 1.75→0.95 cm로 내려감.

## 실제 비누처럼: 곧은 칼 + U자 끌 + 물 (2026-10-07)
- 사용자 스크린샷 진단: 둥근 날끝 도장 자국이 겹쳐 거품처럼 울퉁불퉁 + 모든 모서리가 뭉개져 점토 같았다. 물리엔진(실시간 해상도 MPM)은 더 뭉툭해지므로 대신 칼이 남기는 모양을 바꿈.
- 레퍼런스(태국 비누 조각 도구 = 칼 + U/V자 끌, 칼자국은 곧은 모서리로 긁거나 물 묻혀 문질러 지운다, 무른 비누는 부스러짐)에 맞춰:
  - **칼(1) = 곧은 날** `carve(..., 'flat')`: 바닥 평평, 모서리 0.2 mm만 둥글게, 구간 끝 각짐. 획 처음 3 mm는 깊이가 0에서 차올라(비스듬히 파고듦) 시작점 구덩이 없음.
    구간을 날 폭 절반(최대 1.2 mm)만큼 겹치고, 날 방향엔 다듬은 법선(st.nS)을 씀 — 안 그러면 꺾이는 곳에 쐐기 틈·가는 기둥이 남았다.
  - **U자 끌(4)** = 예전 둥근 단면. 칼 메시도 둥근 날끝으로 바뀜.
  - 획 끝: 각진 턱 + 곧은 칼이면 모서리 2~4군데 작은 부스러짐(`sdf.crumble`).
  - 재질: 텍스처를 rgba16float로(r 거리, g 깎인 면 종류, b·a 칼 결 옆방향 l). 칼 면=0.45 mm 간격 결(멀면 흐림)+왁스 광택,
    U자 끌·자른 면=결 없이 매끈, 물로 녹은 면=결 지워짐, 부스러진 곳=거칠고 탁함.
- 미확인: 실제 트랙패드로 그었을 때 시작 램프 3 mm가 적당한지, 결 세기(0.035)가 적당한지.

## 투명·반짝이 비누 (2026-10-07)
- 레퍼런스: 투명 글리세린(녹여 붓기) 비누는 말린 꽃·반짝이를 박아 넣는 용도, 마이카 반짝이는 투명 바탕 속에 떠서 보석처럼 반짝임.
- 비누 종류 6 '투명 꽃잎', 7 '반짝이' (look id 5, 6). `transmit()`: 시선을 1.45로 굴절시켜 비누 속을 0.05 cm 간격 최대 90걸음 지나며
  박힌 것(납작한 꽃잎·작은 기포 / 무작위 방향 반짝이 판: 반사 방향과 맞으면 번쩍)을 쌓고, 빠져나가 다시 굴절된 방향의 작업대·배경을
  흡수(Beer–Lambert)만큼 물들임 + 표면 프레넬 반사. 반짝이는 보는 각도 따라 바뀜(돌려 보면 반짝).
- 미확인: GPU 시간(픽셀마다 최대 90걸음이라 큰 화면에서 무거울 수 있음 — 실제 Chrome 전체 화면 fps 확인 필요).

## 떨어진 조각 레이마칭 · 모양 품은 비누 · 성능 (2026-10-07)
- **떨어진 조각**: 예전엔 1 mm surface nets 메시 → 비스듬한 모서리가 평균 0.4 mm 톱니(0.5 mm 격자면 0.1 mm)로 '깨져' 보였고 재질도 불투명 단색이었다.
  이제 조각마다 0.5 mm 거리장을 r16float 3D 텍스처로 올리고, 상자 뒷면을 그려 그 안을 레이마칭(`CHUNK_WGSL`). 계산은 '원래 좌표'에서 해서
  재질·무늬가 잘린 자리 그대로 이어짐. 행렬: 원래→월드 = T(pos)·R(q)·S·T(-com). 그림자는 둥근 얼룩(blob). 부딪힘 점은 거리장 표면 복셀 200개.
  재질 공용: `MATERIAL_WGSL`, 투과는 `transmitWGSL(이름, 거리장, 법선, 월드점식, 월드방향식, 목표모양)` 템플릿으로 본체/조각이 같이 씀.
- **비누 종류 정리**(사용자 요청): 갤럭시·바다·투명 꽃잎·라벤더 스월 삭제. 남은 것: 모양 품은 비누(id 7), 젤리 층(1), 꿀 벌집(2), 반짝이(6).
  **모양 품은 비누**: 맑은 비누 속에 목표 모양(물고기/토끼, 자유 조각이면 물고기)이 산호색 불투명 비누로 들어 있어 겉에서 보임. 목표 거리장
  텍스처(tgtTex)를 transmit에서 만나면 기울기 법선으로 빛을 받아 그리고 멈춤, 0.5 mm 걸음 안에서 4번 되짚어 계단 제거.
- **성능 실측**(1536×1152 캔버스, 내장 브라우저, 30프레임 GPU 대기 평균, 비누가 화면을 꽉 채운 가까운 장면):
  처음: 젤리 81 ms·꿀 96 ms(비누 속 걸음마다 4겹 fbm) → 걸음 안 노이즈 1겹으로: 36·48 → 꿀 걸음 0.8 mm: 33.
  해상도 100/80/65%: 모양 25.6/16.6/9.1, 젤리 36.3/22.4/14.7, 꿀 33.0/24.4/15.6, 반짝이 27.6/18.3/13.1 ms.
  → **해상도 자동 조절**: 3D 장면을 줄인 텍스처에 그리고 화면으로 늘림(blit). 시작은 약 160만 화소, 프레임 간격 지수평균 >19 ms면 −0.1(최소 0.5),

## 칩도 비누 재질로 (2026-10-07)
- 칩 마디마다 깎여 나온 자리(o = 날끝 + 법선·깊이/2)를 저장 → 정점에 orig(3) 추가(정점 44바이트). `fsChip`이 `medium(orig)`로 그 자리 비누 색을
  가져와 반투명(바탕 불투명도 + 두께/각도만큼 진해짐 + 프레넬)으로 그림. 모양 품은 비누에서 속 모양을 깎은 칩은 산호색 불투명, 반짝이 비누 칩은 반짝이.
  칩은 섞어 그리기(깊이 안 씀)라 그림자 다음, 칼보다 먼저 그린다. 메시용 bind group에 목표 모양 텍스처·샘플러 추가.
- 해상도 자동 조절: 60 ms 넘게 빈 프레임 간격(숨은 탭·정지)은 판단에서 뺌 — 안 그러면 돌아왔을 때 화질이 최저(50%)로 떨어져 있었다.

## 칼 자국이 어색해 보이던 문제 (2026-10-07)
- 원인: 비누를 전부 투명 재질로 바꾼 뒤, 칼·끌로 깎은 면도 거푸집 면처럼 유리같이 매끈하게 굴절시켰다. 그래서 (1) 홈이 렌즈·프리즘처럼 속(층·물고기)을
  어긋나게 보이고, (2) 깊은 홈 벽·둥근 모서리로 들어간 시선이 크게 꺾여 작업대가 갈색 줄로 비쳤고, (3) 칼 결(법선 흔들기)이 굴절에도 들어가 줄무늬로 일렁였다.
  깎인 면 종류(g 채널)·왁스 광택은 예전 불투명 경로에만 있어 투명 경로에서 무시되고 있었다.
- 레퍼런스: 투명 비누는 갓 자르면 단면이 뿌옇게 흐려지고 손으로 닦아야(물로 문지르면) 맑아진다 (Matsuyama 투명 비누 제조, Harvard GSD 위키 글리세린 베이스).
- 해결: 칼·U자 끌·자르기·부스러진 면 = 서리 낀 면(frost 0.8): 굴절 법선을 시선 쪽으로 85%까지 눕혀 덜 꺾고, 반사 줄이고, 비쳐 보이는 색을 흰빛 쪽으로
  밝힌 간유리 막(속 색 유지) + 넓고 약한 광택. 물로 녹인 면·젖은 동안은 다시 맑음. 칼 결은 광택에만, 굴절은 원래 법선(nGeo).
- 남은 것: 물로 닦아 맑아진 깊은 홈의 둥근 모서리는 여전히 렌즈처럼 작업대를 갈색 줄로 비침(물리적으로 그럴 법하지만 0.5 mm 격자라 모서리가 실제보다 둥글어 과함).

## 모양 품은 비누: 깎인 단면이 둥글게 보이던 문제 (2026-10-07)
- 원인: 속 모양(물고기·토끼)을 늘 속 모양 SDF 기울기로 비춤 → 칼로 평평하게 자른 단면도 원래 몸통 곡면처럼 음영. y=1.6 수평 단면 297점 측정: 실제 법선과 평균 81°(중앙 86°), 96%가 45° 넘게 어긋남.

- 확인: 수평 단면이 평평한 무광 면으로 보임(스크린샷). 칼 홈이 물고기를 지나는 경우는 아직 눈으로 확인 안 함.
- 입력 세기 조사: Chrome(내장 브라우저 Chromium 152 포함)은 `webkitForce` 없음, 트랙패드 pressure는 0.5 고정. Safari만 webkitForce(0~3) 제공.

## 조사만 함 (2026-10-07, 아직 안 고침)
### 물 묻힌 뒤 모양 품은 비누가 얼룩덜룩 (갈색·회청색)
- 재현: look 7, z=0.95 평면 자르기 → 칼 6줄(깊이 1 mm) → 물 3줄 → 2초 흐름. 배포판·로컬 둘 다 나옴.
- 원인 A: 물이 닿으면 mark=100(kind 0.39, '녹아 매끈')으로 바꿔 뿌연 막을 영구히 걷는데, 녹는 양(최대 ~0.2 mm대)은 칼 턱·부스러진 끝의 요철보다 작아 모양은 여전히 거칠다 → 거친 면을 맑은 유리로 굴절시켜 바닥·배경이 조각나 보임. A/B: mark 100→150(뿌옇게)로 바꾸면 우상단 얼룩 사라짐.
- 원인 B: transmit이 비누 밖으로 한 번 나가면 바로 바닥/배경을 찍고 다시 들어가지 않는다. 칼 턱(계단) 벽에서 굴절 광선이 1 mm 안에 턱 위로 빠져나가 → 속 물고기 대신 바닥(갈색)·배경(회청) 띠. 임시 디버그 색(초록=1 mm 안 이탈)이 회청·갈색 띠와 정확히 겹침.
- 부가: 젖은 하이라이트 pow 160이 거친 법선에서 흰 점으로 반짝임.
### 부스러기 없이 '쓱' 소리
- 원인: 바탕음 조건이 frameVol > 0 이라 1e-10 cm³ 같은 부동소수 찌꺼기에도 켜짐, 크기는 깎인 양이 아니라 속도·깊이로 정함. 한 획 안에서 왔다 갔다 하면 pick이 획 시작 전 표면(st.snap)을 따라가 이미 판 홈 위 허공을 긁음 → 540구간 중 165구간이 vol>0·칩 없음(합 5.7e-10).

## 허공 조각 + 칼 단면·칩·공간감 개편 (2026-10-07, 로컬, 미배포)
