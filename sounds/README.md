# 녹음 넣는 곳

1. 이 폴더에 `<종류>_<번호>.m4a` 이름으로 넣는다 (mp3·wav·ogg도 됨). 예: `cut_thin_01.m4a`, `scrape_a.m4a`
2. `python3 tools/sound_manifest.py` → `manifest.json`이 다시 만들어진다
3. 새로고침 → 첫 클릭 때 불러온다. `?debug` 패널 아래에 종류별 개수가 보인다

없는 종류는 지금의 합성음이 그대로 난다. 일부만 넣어도 된다.

| 종류 | 내용 | 권장 개수 |
|---|---|---|
| `cut_thin` | 얇게 깎는 "사각" 한 번 (0.05~0.2초) | 30~50 |
| `cut_deep` | 깊게 파내는 "사각" 한 번 | 30+ |
| `scrape` | 일정한 속도로 이어서 깎는 긴 녹음 (20~40초) | 2~3 |
| `sand` | 문지르기 짧은 것 | 20 |
| `sand_loop` | 이어서 문지르는 긴 녹음 | 1~2 |
| `chip` | 칩이 떨어지는·부딪히는 "톡" | 20 |
| `hit_big` | 덩어리 "쿵" | 10 |
| `slice` | 덩어리 자르기 "썩" | 10 |
| `drip` | 물방울 "똑" | 10 |

- 한 번짜리(`cut_*`, `sand`, `chip`, `hit_big`, `slice`, `drip`)는 소리 시작 지점에서 바로 자르고(1~2 ms 페이드인), 꼬리는 10~30 ms 페이드아웃.
- 긴 녹음(`scrape`, `sand_loop`)은 앞뒤 손 움직임 소리만 잘라 내면 된다. 90 ms 조각으로 무작위로 잘라 겹쳐 튼다.
- 울림 없이(dry), 모노 48 kHz. 같은 종류끼리 음량을 맞춘다. 종류 간 크기는 `src/sound.js`의 `SAMPLE_GAIN`과 `?debug`의 `rec`로 맞춘다.
- 녹음이 있으면 합성음은 `synth`(기본 0.25)만큼 위에 얹힌다. 녹음만 듣고 싶으면 `?debug`에서 0으로.
